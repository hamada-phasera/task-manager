# tsunokawa-phase3 — 角川流通倉庫株式会社 コーポレートサイト・リニューアル Phase 3(デザインモック)

エンタメグッズB2B物流3PL「角川流通倉庫株式会社(読み:ツノカワ)」のコーポレートサイト・モック。
3Dモチーフは倉庫やトラックではなく **「波動」**(発売日・イベントで出荷量が突発的に跳ねること)。
Three.js のパーティクル波面がスクロールで3幕遷移します。

> ⚠️ モック段階のため `noindex, nofollow` を設定済み。フォームはどこにも送信されません。

## ローカルでの確認方法

ESM と `fetch('data/figures.json')` を使うため、**必ずローカルサーバー経由で開いてください**
(`file://` 直開きでは数値が注入されずエラーバーが表示されます)。

```bash
cd tsunokawa-phase3

# どれか1つ
python3 -m http.server 8000
# または
npx serve .
# または
npx http-server -p 8000
```

ブラウザで <http://localhost:8000/> を開く。

## 数値SSOT規律(data/figures.json)

- サイト内に表示される**全数値**は `data/figures.json` から JS で注入する。HTML/JS への数値ハードコードは禁止。
- HTML 側のフックは `data-fig` / `data-count`(カウントアップ)/ `data-hud`(HERO の HUD ラベル)/ `data-company` / `data-locations-count` のみ。
- `approval.status: "pending"` の値には黄色 `#F5C518` の **「要承認」バッジが自動表示**され、`title` に矛盾内容が入る。S4 下部には矛盾一覧のフットノートも自動生成される。

## 波動(3D)の3幕遷移

| 幕 | 区間 | 波面 | 色 |
| --- | --- | --- | --- |
| 第1幕 | S1 HERO | 荒波(fbmノイズ・大振幅) | ウォーム `#FF7A59` 優勢 |
| 第2幕 | S3 STORY | 整流(正弦波に収束) | 遷移 |
| 第3幕 | S4 NUMBERS以降 | 静止(平坦格子・まれに1点脈動) | シアン `#3FE0C5` 優勢 |

- canvas は `position: fixed` で背面。スクロール量からフェーズ(0..2)を算出し **LERP(係数0.07)** で平滑化。
- **遅延初期化**: WebGL は `load` 後のアイドル時に起動(LCP は HERO テキスト)。
- **prefers-reduced-motion**: WebGL を起動せず静止背景(CSSグラデーション)に切替。マーキー・スクランブル・カウントアップも停止。
- 手続き的ジオメトリのみ。外部3Dアセット・外部CDNは不使用。

## 参照GIF(igloo.inc)の踏襲状況

| 踏襲ポイント | 実装 |
| --- | --- |
| 霧のかかった単色3D空間 | 奥行き・端フェード(疑似フォグ)+ 単色系パレット |
| HUD風モノスペース計測ラベル | HERO の波面周囲に実データ(SKU・誤出荷率・出荷能力等)を浮遊表示 |
| テキストスクランブル演出 | セクションラベル(欧文)に適用。和文見出しはブラーフェード |
| 色収差+フロストのシーン遷移 | 幕遷移中のみ点スプライトRGBオフセット+フロストベール |
| 中央の主役がスクロールで変容 | 氷塊→**波動の波面**に置換し、荒波→整流→静止と変容 |

GIF 本体は未添付のため、細部(遷移のタイミング・ラベルの動き)は受領後に追従調整の余地あり。

## デザインDNA

- 背景 `#07090E` / 面 `#0D1119` / テキスト `#EDF1F7` `#A7B0C0`
